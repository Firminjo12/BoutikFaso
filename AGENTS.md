# Consignes du projet

- Avant de réaliser une partie de l’application, consulter les éléments pertinents du dossier `maquette/` pour respecter les écrans et le rendu attendu.
- Consulter également les éléments pertinents du dossier `planing/` pour suivre le périmètre et l’ordre prévus.
- Quand une demande concerne une partie précise, croiser la maquette et le planning correspondants avant de modifier le code.
- Pour l’instant, développer l’application sans backend.
